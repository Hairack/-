# Ручка (Ruchka) - Мессенджер

Простой и безопасный мессенджер с сквозным шифрованием.

## Структура проекта

- `client/` - Android приложение (Kotlin)
- `server/` - Серверная часть (Rust)

## Запуск сервера

1. Установите Rust: https://rustup.rs/
2. Перейдите в папку сервера:
   ```bash
   cd server
   ```
3. Запустите сервер:
   ```bash
   cargo run
   ```
4. Сервер запустится на http://127.0.0.1:8080

## API Endpoints

- `GET /` - Проверка работы сервера
- `POST /api/send` - Отправка сообщения
  ```json
  {
    "sender_id": "user1",
    "receiver_id": "user2",
    "content": "зашифрованное_сообщение"
  }
  ```
- `GET /api/messages?user_id=user1&contact_id=user2` - Получение истории переписки

## Запуск Android приложения

1. Откройте папку `client` в Android Studio
2. Дождитесь синхронизации Gradle
3. Запустите на эмуляторе или устройстве

## Безопасность

Все сообщения шифруются на стороне клиента перед отправкой. Сервер хранит только зашифрованные данные.
